# ثيم أسس ميديا — AOSS MEDIA Salla Theme

ثيم سلة (Twilight) سينمائي خاص بأسس ميديا، مبني على ثيم **رائد** الرسمي من سلة، مع طبقة هوية كاملة:
أبيض وأسود، خط **IBM Plex Sans Arabic** للعربي و**Space Grotesk** للإنجليزي، ومدارات ضوئية متحركة.

## ما الذي أُضيف على ثيم رائد

### أقسام للصفحة الرئيسية (تُعدَّل من محرر سلة بدون كود)
| القسم | الملف |
|---|---|
| أسس \| الواجهة السينمائية | `src/views/components/home/aoss-hero.twig` |
| أسس \| الخدمات (بطاقات بروابط) | `aoss-services.twig` |
| أسس \| لماذا نحن | `aoss-features.twig` |
| أسس \| الخدمات والباقات (منتجات) | `aoss-products.twig` |
| أسس \| الكوادر | `aoss-talent.twig` |
| أسس \| كيف نعمل | `aoss-process.twig` |
| أسس \| لمن نقدم خدماتنا | `aoss-audiences.twig` |
| أسس \| الأسئلة الشائعة | `aoss-faq.twig` |
| أسس \| دعوة ختامية | `aoss-cta.twig` |

كل النصوص الافتراضية معبأة بمحتوى أسس ميديا، وتدعم العربية والإنجليزية.

### إعدادات عامة (محرر الثيم ← الإعدادات)
- رقم واتساب (يُستخدم في الزر العائم والشريط وأزرار عرض السعر).
- إظهار/إخفاء زر واتساب العائم.
- الشريط الإعلاني العلوي ونصه.
- اسم تصنيف الكوادر (الافتراضي: `الكوادر`).

### صفحة المنتج
- زر «اطلب عرض سعر مخصص عبر واتساب» برسالة جاهزة فيها اسم الخدمة، مع نقاط الثقة.
- **ملف الكادر:** أي منتج داخل تصنيف الكوادر يظهر بشارة «TALENT PROFILE»، و«سعر الساعة» بجانب السعر، وزر «احجز هذا الكادر عبر واتساب».

## الكوادر (ميكب آرتست، مودل، قهوجي…)
1. أنشئ تصنيفًا اسمه **الكوادر** (أو أي اسم، واكتبه في إعدادات الثيم).
2. أضف كل شخص كمنتج داخل هذا التصنيف — يُفضّل نوع **حجوزات** ليختار العميل التاريخ والساعات:
   - **الاسم:** اسم الكادر (حقيقي أو فني).
   - **العنوان الفرعي:** التخصص، مثل «ميكب آرتست — الرياض».
   - **الصور:** معرض أعماله (الصورة الأولى = الصورة الشخصية).
   - **السعر:** سعر الساعة.
   - **الوسوم:** التخصص والمدينة واللغات (تساعد في البحث والفلترة).
3. أضف قسم «أسس | الكوادر» للرئيسية واختر التصنيف.

> احصل على موافقة مكتوبة من كل كادر على نشر صوره واسمه قبل إضافته.

## التشغيل والنشر

المتطلبات: Node.js 18 أو أحدث، و`pnpm`، وحساب GitHub، وحساب في بوابة شركاء سلة <https://portal.salla.partners>.

```bash
npm install -g @salla.sa/cli pnpm
salla login
salla theme create          # اختر اسمًا مثل aoss-media-theme — ينشئ مستودع GitHub ومجلدًا محليًا
```

انسخ **كل محتويات هذا المجلد** فوق المجلد الذي أنشأه الأمر السابق (استبدل الملفات)، ثم:

```bash
cd aoss-media-theme
pnpm install
salla theme preview         # معاينة مباشرة على متجر تجريبي مع تحديث فوري
```

بعد المراجعة:

```bash
git add -A && git commit -m "AOSS MEDIA theme" && git push
salla theme publish
```

قبل النشر عدّل في `twilight.json`: `repository` و`author_email`.
